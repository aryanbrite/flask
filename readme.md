## Running Locally

1) Clone the repository:

```sh
git clone https://github.com/aryanbrite/flask.git 
```

2)
 ```sh
 cd flask
```

3) 
```sh
 cd flask
```

4) MACOS
```sh
python3 -m venv .venv
source .venv/bin/activate
```

or

Windows

```sh
python -m venv .venv
.venv\Scripts\activate
```
4) MACOS
```sh
pip install -r requirements.txt
```

## Run the App
```sh
python app.py
```

open http://127.0.0.1:5000
